# Contributing to AEGIS NEXUS AI

Thank you for your interest in contributing to AEGIS NEXUS AI!

## Getting Started
1. Fork the repository
2. Clone your fork
3. Set up development environment (see README.md)
4. Create a feature branch

## Development Guidelines
- **Python Backend**: Follow PEP 8, use type hints, pass Ruff linting
- **TypeScript Frontend**: Use strict TypeScript, follow React best practices
- **Testing**: Add tests for new functionality
- **Commits**: Write clear, descriptive commit messages
- **Security**: Never commit secrets or credentials

## Pull Request Process
1. Ensure all tests pass
2. Update documentation if needed
3. Submit PR with clear description of changes
